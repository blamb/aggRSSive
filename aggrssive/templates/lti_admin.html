Register with Moodle (dynamic registration)

  1. In Moodle: Site administration → Plugins → Activity modules → External tool → Manage tools.
  2. Paste this into Tool URL and click Add LTI Advantage:
  3. A window opens, aggRSSive registers itself and the window closes. If the tool shows as Pending, click Activate.
  4. Optionally, in the tool's settings, tick Show in activity chooser and as a preconfigured tool and enable Supports Deep Linking.

If the platform can't reach this server

Moodle verifies aggRSSive's signatures by fetching the keyset URL above. If the two sites live on the same cloud (e.g. both on Reclaim Cloud) that fetch can fail, because the platform resolves this hostname to a private address. Fix: in Moodle, edit the registered tool, set Public key type to RSA key and paste this. Nothing else changes.

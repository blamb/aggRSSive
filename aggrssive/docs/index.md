# Getting started with aggRSSive

aggRSSive collects feeds, lets a group tag and classify them together, and turns any selection into an **aggRSSive**: a live, filtered bundle you can embed on a web page, subscribe to as a feed, or drop into a course in Moodle, Canvas or any other LTI platform.

## The five-minute tour

1. **Find feeds.** *Find feeds* in the menu shows every source anyone has added, browsable by tag and by classification heading. Tick the ones you want; they collect in the **♥ Heart-Cart** at the bottom right.
2. **Add feeds.** *+ Add feed* takes any web address — a blog, a journal, a YouTube channel, a podcast — and finds its feed. Or import an OPML file from your feed reader.
3. **Make an aggRSSive.** From the Heart-Cart, name your bundle and click *Create*. It's live immediately.
4. **Filter and curate.** On the bundle's *edit* page, add rules ("only items mentioning *assessment*", "drop anything about webinars"), pin the items that matter, hide the ones that don't, add a note.
5. **Publish.** Every public aggRSSive has embed code, RSS/Atom/JSON feeds, and can be added to a course with *External tool → Select content*.

## Where things are

| Menu item | What's there |
|---|---|
| **Find feeds** | Search, tags, classification, and the Heart-Cart |
| **aggRSSives** | Bundles: yours and everyone's public ones |
| **+ Add feed** | Add one feed or import many |
| **Help** | These pages |
| **Admin** | (site and full admins) LTI platforms, users, settings |

## Accounts

Anyone with an account can add sources, tag and classify them, and build and publish aggRSSives. Everything shared — sources, tags, classification — belongs to the collection, not to one person. Your aggRSSives are yours to edit; others can see and reuse the public ones.

See [Roles](roles) for what site admins and full admins can do.
